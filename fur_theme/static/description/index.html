Get started

Setup in five minutes

  1. Install Fur - Furniture eCommerce Theme (dependencies: Website Sale, Custom payment provider).
  2. Website > Configuration > Websites > Fur Theme: brand name, footer logo, hotline, WhatsApp, Zalo, Messenger, opening hours, buying guide.
  3. Upload your logo in Website > Configuration > Settings.
  4. Tick Show on Homepage on eCommerce categories and Featured on Homepage on products and projects.
  5. Set your bank account on the Bank transfer payment provider.
